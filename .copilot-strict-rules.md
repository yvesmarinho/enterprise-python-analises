## 🎯 Regras Fundamentais

### 1. Organização de Arquivos
- ✅ **SEMPRE** manter a raiz do projeto limpa
- ✅ **SEMPRE** utilizar as pastas corretas para cada tipo de arquivo
- ❌ **NUNCA** criar arquivos temporários na raiz
- ❌ **NUNCA** deixar arquivos de log, cache ou backup na raiz

**Estrutura Obrigatória**:
```
enterprise-python-analysis/
├── docs/              # Documentação APENAS
├── data/               # Dados de entrada APENAS
├── scripts/            # Scripts Python APENAS
├── reports/            # Relatórios gerados APENAS
├── .secrets/           # Credenciais (não versionado)
├── main.py             # Script principal (raiz OK)
├── pyproject.toml      # Configuração Python (raiz OK)
├── README.md           # Documentação principal (raiz OK)
└── migration_plan.json # Artefato principal (raiz OK)
```

### 2. Documentação de Sessões
- ✅ **SEMPRE** criar pasta de sessão em `docs/sessions/YYYY-MM-DD/`
- ✅ **SEMPRE** documentar atividades em `TODAY_ACTIVITIES_YYYY-MM-DD.md`
- ✅ **SEMPRE** criar `SESSION_RECOVERY_YYYY-MM-DD.md` ao iniciar sessão
- ✅ **SEMPRE** criar `SESSION_REPORT_YYYY-MM-DD.md` ao finalizar sessão
- ❌ **NUNCA** sobrescrever documentação de sessões anteriores

### 3. Recuperação de Contexto (MCP)
- ✅ **SEMPRE** ler arquivos da sessão anterior ao iniciar
- ✅ **SEMPRE** recuperar: INDEX.md, TODO.md, TODAY_ACTIVITIES, SESSION_RECOVERY
- ✅ **SEMPRE** atualizar data nos arquivos principais (INDEX, TODO)
- ✅ **SEMPRE** manter histórico completo de atividades

### 4. Versionamento e Backups
- ✅ **SEMPRE** manter arquivos originais intactos
- ✅ **SEMPRE** versionar documentação por data
- ❌ **NUNCA** deletar arquivos sem backup
- ❌ **NUNCA** sobrescrever dados importantes

### 5. Nomenclatura de Arquivos
- ✅ **SEMPRE** usar formato `YYYY-MM-DD` para datas
- ✅ **SEMPRE** usar `snake_case` para scripts Python
- ✅ **SEMPRE** usar nomes descritivos e autoexplicativos
- ❌ **NUNCA** usar espaços em nomes de arquivos
- ❌ **NUNCA** usar caracteres especiais (exceto _ e -)

## 🔄 Workflow de Trabalho

### Início de Sessão
1. ✅ Criar pasta `docs/sessions/YYYY-MM-DD/`
2. ✅ Criar `SESSION_RECOVERY_YYYY-MM-DD.md`
3. ✅ Ler sessões anteriores (INDEX, TODO, ACTIVITIES)
4. ✅ Atualizar data em INDEX.md e TODO.md
5. ✅ Criar `TODAY_ACTIVITIES_YYYY-MM-DD.md`

### Durante a Sessão
1. ✅ Documentar cada ação significativa
2. ✅ Atualizar TODO.md conforme tarefas completadas
3. ✅ Manter organização de pastas
4. ✅ Validar código e scripts criados

### Final de Sessão
1. ✅ Criar `SESSION_REPORT_YYYY-MM-DD.md`
2. ✅ Atualizar STATUS no INDEX.md
3. ✅ Marcar tarefas completadas no TODO.md
4. ✅ Documentar próximos passos
5. ✅ Criar `FINAL_STATUS_YYYY-MM-DD.md` se necessário
