## 🎯 Propósito

---

## 🔒 Níveis de Enforcement

### Nível 1: BLOQUEIO IMEDIATO ⛔
**Ações que devem ser IMPEDIDAS automaticamente**

- ❌ Versionar arquivos em `.secrets/`
- ❌ Sobrescrever arquivos de sessão anteriores sem backup
- ❌ Deletar arquivos de documentação sem confirmação
- ❌ Criar arquivos na raiz sem justificativa

**Ação**: Bloquear operação + Alertar usuário + Sugerir alternativa

---

### Nível 2: AVISO OBRIGATÓRIO ⚠️
**Ações que requerem confirmação explícita**

- ⚠️ Modificar estrutura de pastas estabelecida
- ⚠️ Alterar nomenclatura de arquivos importantes
- ⚠️ Executar operações em produção
- ⚠️ Deletar dados coletados

**Ação**: Pausar + Explicar impacto + Solicitar confirmação

---

### Nível 3: VALIDAÇÃO RECOMENDADA 💡
**Ações que devem ser revisadas**

- 💡 Criar novos scripts sem documentação
- 💡 Modificar código existente sem testes
- 💡 Adicionar dependências não documentadas
- 💡 Pular etapas do workflow

**Ação**: Avisar + Sugerir melhorias + Permitir se confirmado

## 📋 Validações Automáticas

### Validação de Início de Sessão

```python
def validate_session_start(date: str) -> bool:
    """Valida se todos os requisitos de início de sessão foram atendidos"""

    checks = {
        "session_folder": f"docs/sessions/{date}/" exists,
        "session_recovery": f"SESSION_RECOVERY_{date}.md" exists,
        "today_activities": f"TODAY_ACTIVITIES_{date}.md" exists,
        "index_updated": "INDEX.md" contains current date,
        "todo_updated": "TODO.md" contains current date,
        "previous_context": Previous sessions were read
    }

    return all(checks.values())
```

**Ação se falhar**:
1. Listar checks faltantes
2. Criar arquivos necessários automaticamente
3. Alertar sobre contexto incompleto

---

### Validação de Organização de Arquivos

```python
def validate_file_organization() -> bool:
    """Valida se arquivos estão nas pastas corretas"""

    rules = {
        "root_clean": len([f for f in root if not is_allowed(f)]) == 0,
        "scripts_in_scripts": all python files in /scripts/,
        "docs_in_docs": all .md files in /docs/,
        "data_in_data": all .json/.csv in /data/,
        "reports_in_reports": all reports in /reports/,
        "secrets_not_versioned": .secrets/ in .gitignore
    }

    return all(rules.values())
```

**Ação se falhar**:
1. Listar arquivos fora do lugar
2. Sugerir reorganização
3. Oferecer migração automática

def validate_documentation(session_date: str) -> bool:

## 🚨 Tratamento de Violações

### Violação de Nível 1 (Crítica)
**Exemplo**: Tentar versionar arquivo em `.secrets/`

**Resposta**:
1. 🛑 **BLOQUEAR** operação imediatamente
2. 📢 **ALERTAR** usuário: "CRÍTICO: Tentativa de versionar credenciais"
3. 🔧 **SUGERIR**: "Mova o arquivo para .secrets/ e adicione ao .gitignore"
4. 📝 **DOCUMENTAR** violação em log de sessão

---

### Violação de Nível 2 (Alta)
**Exemplo**: Criar arquivo na raiz sem justificativa

**Resposta**:
1. ⏸️ **PAUSAR** operação
2. ❓ **QUESTIONAR**: "Por que este arquivo deve estar na raiz?"
3. 💡 **SUGERIR**: "Considere mover para /scripts/ ou /data/"
4. ✅ **PERMITIR** se usuário justificar claramente

---

### Violação de Nível 3 (Média)
**Exemplo**: Criar script sem docstring

**Resposta**:
1. ⚠️ **AVISAR**: "Script criado sem documentação"
2. 📚 **SUGERIR**: "Adicione docstrings para melhor manutenibilidade"
3. ✅ **PERMITIR** execução
4. 📝 **REGISTRAR** como melhoria futura
